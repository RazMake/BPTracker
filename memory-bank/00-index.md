## Rules for this memory bank

1. **Facts, not prose.** If a statement is not actionable, delete it.
2. **One topic per file.** If a file needs a table of contents, split it.
3. **Record the "why".** The code shows what; this records why, and what was rejected.
4. **Correct rather than append.** Out-of-date guidance is worse than no guidance.
5. **A decision that constrains future work becomes an ADR**, not a bullet buried in a file.
